## Search Console setup

1. Add `https://moneybee.yellowbytes.dev/` as a URL-prefix property in [Google Search Console](https://search.google.com/search-console/).
2. Choose the HTML tag method and copy only the `content` value of the supplied verification tag.
3. The Pages workflow includes the supplied verification token as a fallback. For another build environment, set `GOOGLE_SITE_VERIFICATION` to the same value.
4. Publish the resulting export, confirm the verification tag is in the homepage source, and click Verify in Search Console.
5. Submit `https://moneybee.yellowbytes.dev/sitemap.xml`. Inspect the homepage, features page, and one article; request indexing if appropriate.
6. Review Page indexing and Core Web Vitals after Google has collected data. Verification and sitemap submission do not guarantee indexing or ranking.

A Domain property can instead use DNS verification, without a website verification tag. Account ownership and DNS access are needed for that option.

## Backlink plan

- First week: update the owned Google Play website link and publisher profile to the canonical site after publication. Confirm the public app name and screenshots match the website.
- Second week: prepare a factual product listing for relevant Android and expense-tracking directories. Link directly to the homepage or feature page. Check each directory's submission rules and avoid paid ranking links.
- Third week: publish a worked notebook example using fictional data, showing household, trip, and shared-fund records. Link it from the getting-started guide and share it only in communities that allow product examples.
- Fourth week: identify a small set of Android reviewers or personal finance writers whose coverage fits MoneyBee. Offer a clear product walkthrough and factual feature notes. Outreach requires the owner's approval; no messages have been sent.
- Monthly: track referring pages, referral visits, and Search Console links. Prefer relevant editorial references and fix broken incoming destinations with host redirects.

Before outreach, review the inherited app-comparison article: prices, ratings, competitor features, and launch claims have not been verified by this SEO implementation.

## Maintain the checks

Run `npm run typecheck`, `npm test`, `npm run build`, then `npm run seo:check`. The Pages workflow already runs the export checker before uploading its artifact. Regenerate committed image variants with `npm run images:optimize` when source assets change.

Guidance: [Next.js metadata](https://nextjs.org/docs/app/getting-started/metadata-and-og-images), [Google canonical URLs](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls), and [Google indexing requirements](https://developers.google.com/search/docs/essentials/technical).
